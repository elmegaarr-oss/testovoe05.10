# Асинхронный сервис процессинга платежей (FastAPI + aio-pika)

Микросервис предназначен для асинхронного приема и гарантированной обработки платежей на базе паттерна Transactional Outbox и архитектуры очередей RabbitMQ.

## 🚀 Архитектурные решения и паттерны

1. **Transactional Outbox Pattern**: Исключает потерю событий при сбоях сети. Создание платежа и регистрация события происходят атомарно внутри одной ACID-транзакции PostgreSQL. Специальный фоновый процесс внутри FastAPI (`app/main.py`) считывает неотправленные сообщения и транслирует их в RabbitMQ с блокировкой строк `FOR UPDATE SKIP LOCKED`.
2. **Изоляция слоев и типов данных**: Сервис полностью переведен на использование нативного, легковесного драйвера `aio-pika`, работающего с сырыми массивами байт (JSON-строками). Это исключает конфликты асинхронных циклов (`event-loop`) и гарантирует мгновенное обновление статусов транзакций на диске.
3. **Защита от дубликатов (Idempotency)**: Реализована проверка повторных запросов на основе уникального заголовка `Idempotency-Key` с уникальным ограничением на уровне СУБД. Повторные вызовы мгновенно возвращают сохраненный результат без создания дубликатов в БД.
4. **Dead Letter Queue (DLQ)**: Настроена автоматическая маршрутизация сообщений при недоступности принимающей стороны. Механизм `tenacity` выполняет 3 экспоненциальные попытки ретраев вебхука. При сохранении сбоя сети RabbitMQ перенаправляет сообщение в обменник `payments.dlq.exchange` и очередь `payments.dlq`.

## ⚡ Результаты нагрузочного тестирования

В ходе стресс-тестирования конкурентным пулом потоков были зафиксированы следующие показатели:
- **Общее время отправки пула из 50 транзакций**: 0.62 сек.
- **Мгновенный ответ API (`202 Accepted`)**: ~14-17 мс.
- **Пропускная способность эндпоинта (Throughput)**: **80.2 запросов/сек** под параллельной конкурентной нагрузкой.

## 🛠️ Инструкция по запуску

1. Сбросьте кэш образов и тома старых сессий СУБД:
   ```bash
   docker compose down --volumes --remove-orphans
   ```
2. Запустите сборку и контейнеры инфраструктуры:
   ```bash
   docker-compose build --no-cache && docker-compose up
   ```
3. После старта Uvicorn запустите скрипт автоматизированного тестирования в параллельном окне терминала:
   ```bash
   python run_tests.py
   ```
